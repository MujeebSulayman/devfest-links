Your first week

Build one agent that pays for one thing. All on a testnet, with play money, for free.

  1. Learn the patternAsk, see the price, pay, receive. Read the x402 overview.
  2. Get a testnet wallet and free test USDCPick Base Sepolia on the Circle faucet.
  3. Run an exampleClone the x402 repo and run a client and server example.
  4. Give your agent a wallet tool, never the keyCap each payment, set a daily budget, approve which sites it can pay.
  5. Give it an identityRead ERC-8004 and list your agent’s name, skills and where to reach it.
